# dcnew —— 北京市东城区新闻监测爬取 CLI（CLI-1.0 发布版）

基于 **[Scrapling](https://github.com/D4Vinci/Scrapling)**（自适应网页抓取引擎）与
**[GNE / GeneralNewsExtractor](https://github.com/GeneralNewsExtractor/GeneralNewsExtractor)**
（通用新闻正文提取器）构建，持续监测国内主要信息门户与官方新闻平台上
与**北京市东城区**相关的新闻，并导出与人工统计模板一致的 Excel 周报。

数据源注册表共 **57 个**：检索/聚合型 5 个、列表型 46 个、报纸电子版 6 个。
注册数不等于稳定产出数——站点改版、反爬策略与地域可达性都会影响实际命中，
请以 `dcnew doctor` 的实测结果为准（见下文"覆盖与健康检查"）。

## 命令体系

```bash
dcnew start              # 从现在开始后台监听（守护进程 + 日志）
dcnew start 20251010     # 从 2025-10-10 起补爬历史新闻，随后进入常态监听
dcnew stop               # 停止后台监听
dcnew status             # 状态查询（PID / 心跳 / 中断提示 / 数据量）
dcnew crawl              # 前台立即执行一轮抓取（调试用）
dcnew download           # 从数据库导出最近一周（默认 7 天）生成 Excel
dcnew download 3         # 从数据库导出最近 3 天
dcnew download 3 --refresh  # 先联网抓取一轮入库再导出
dcnew latest             # 终端简洁列举最近 10 条新闻
dcnew latest 20          # 终端列举最近 20 条新闻
dcnew doctor             # 并发体检全部数据源（不写库，约 30 秒）
dcnew doctor 7           # 以 7 天回看窗口体检
```

`start` 可选 `--interval 分钟`（默认 20 分钟一个监听周期）；
`download` 默认直接读取数据库现有数据（秒级、不联网），
可用 `--out 路径` 指定 Excel 输出位置，`--refresh` 先抓取一轮再导出。

启动方式二选一：
- 项目根目录执行 `./dcnew <命令>`（自动寻找 `.venv` 或系统 Python3）；
- `pip install .` 后全局使用 `dcnew <命令>`（pyproject.toml 已配置入口）。

## 数据源（注册 57 个）

**一、检索/聚合型（5）**
央视网、中国日报网、澎湃新闻、百度资讯（全网聚合）、今日头条搜索（全网聚合）。
聚合源会尽量提取新闻的**原始发布媒体**与**原始发布时间**，而不是记成聚合平台。

**二、列表型（46）**
覆盖中央官媒、北京本地媒体、行业媒体与商业门户，包括但不限于：
人民网、新华网、中新网、光明网、央广网、国际在线、中工网、中青在线、
中国青年网、中国经济网、中国科技网、瞭望、半月谈、人民政协网、中国网、
海外网、求是网、中国共产党新闻网、中国政府网、中国警察网、法治日报、
健康报网、文旅中国、中国妇女网、未来网、人民论坛网、中国质量新闻网、
证券时报网、东方财富网、每日经济新闻、界面新闻、21财经、千龙网、新京报、
京报网、北青网、首都之窗、东城区人民政府网、凤凰网、大公网、文汇网、
香港商报、中评网、民主与法制网、网易、搜狐。
完整清单与 URL 规则以 `dcnews/sources.py` 注册表为准。

部分站点（如央广网、中国青年网）使用 GBK/GB18030 编码，已做专门解码；
列表源除主站外，也会抓取已核实的北京/地方频道，提高区级稿件命中率。

**三、报纸电子版（6）**
北京日报、北京晚报、北京青年报（京报集团数字报）、人民日报电子版、
光明日报电子版、北晚在线（takefoto.cn）。

电子报版面按日期组织 URL，`dcnew start 日期` 可回溯补爬，
**默认最多回溯 180 天**（`config.EPAPER_MAX_BACKFILL_DAYS`）。
京报集团数字报要求 `Referer` 请求头（已内置）；同一站点不同日期的页面编码可能
不一致，已做 UTF-8 / GB18030 自动探测。摘要字段写入版面信息
（如"【版面】第3版·北京新闻"），对应人工统计表的版面列；
光明日报休刊日自动跳过。

## 覆盖与健康检查

`dcnew doctor` 并发探测全部注册源（不写库），报告中同时给出两列：

- **候选数**：页面解析出的链接数，反映"抓得到多少"；
- **命中数**：再经东城区关键词甄别后的条数，反映"对本项目有多少有效产出"。

状态含义：
- `√` 存活且有命中；
- `△ 可达但本窗口无候选` / `△ 可达，但关键词零命中`：源本身可达，但当前窗口
  没有相关内容或解析规则需要维护；
- `×` 请求或解析异常（有异常源时命令退出码为 1，便于接入定时告警）。

建议在首次部署、站点改版后或定期巡检时运行，以实际命中而非注册数量评估覆盖。

## 数据质量

- **三级关键词甄别**：T1 强命中（"东城区""北京东城"等）、T2 一般命中、
  T3 地域语境（北京本地媒体 + 街道名等），按级别记录 `match_level`；
- **街道与单位词典**：街道简称做前缀消歧（如避免"石景山"误命中"景山"），
  单位别名归一为规范展示名，并按区领导机关/委办局/街道/区属单位分级排序；
- **其它区消歧**：文档未出现"东城"、却只出现其它区（如"朝阳区文旅局"）时，
  不把通用"区X局"别名计为东城区单位；
- **标题级去重**：同一媒体 + 同一标题视为同一条稿件（跨 PC/移动版、聚合源
  多链接），跨媒体同题仍分别保留，便于统计各媒体发稿量；
- **日期可靠性**：文章页 meta/正文优先，URL 日期仅在路径中且数字边界明确时
  采用，避免从长数字 ID 中截出假日期；
- **Excel 安全**：以 `= + - @` 开头的抓取文本会加前缀，防止被 Excel 当作公式。

> 说明：当前版本仍是"规则 + 词典"甄别。语义层面的噪音（例如仅在相关新闻中
> 顺带提及东城的稿件）计划在 **2.0** 中通过"每日结束时调用大语言模型统一
> 筛查整理"解决，不在本版本范围内。发布前仍建议人工抽查导出结果。

## 安装

```bash
# 项目根目录（DongCheng-News/）
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
pip install .          # 可选：安装 dcnew 命令入口
./dcnew status         # 状态查询（首次运行自动初始化数据库）
```

依赖：`scrapling>=0.5`、`gne`、`requests`、`openpyxl`、
`patchright`、`curl_cffi`、`browserforge`
（后三者是 Scrapling 0.5 内部无条件导入但 wheel 未声明的依赖，本项目已显式列出）。

## 已知限制

- 中国日报检索 API 以相关性排序、偏历史索引，时效覆盖有限；实时性主要由央视
  搜索（时间序）、百度/头条聚合与各列表源保障。
- 百度资讯在数据中心 IP 高频访问时可能触发安全验证；失败时本周期自动跳过。
- 检索型源补爬默认最多翻 10 页（`config.SEARCH_MAX_PAGES`），中断补爬默认
  最多回溯 180 天（`config.MAX_BACKFILL_DAYS`），避免无限回补。
- 东城区人民政府官网在境外/部分数据中心网络可能不可达，届时该源自动跳过。
- 北京时间（北京广播电视台新媒体）、新浪、腾讯新闻、财新、参考消息等站点
  为纯前端渲染且无公开检索接口，未纳入；电视栏目的重点报道通常会有图文版
  同步至京报网等网端源，可间接覆盖。
- 单篇文章详情富化最多尝试 3 次（`config.ENRICH_MAX_ATTEMPTS`），避免死链
  在每个周期被反复请求。

## 平台支持

- **Linux/macOS**：经典双 fork 守护化，脱离终端运行；
- **Windows**：原生后台运行——`DETACHED_PROCESS` 派生独立后台进程
  （`python -m dcnews.daemon`），`dcnew start / stop / status` 均可使用，
  建议在 Windows Terminal / PowerShell 中运行。

## 数据存储位置

数据库、日志、导出 Excel 统一存放在"数据主目录"，按以下优先级解析：

| 优先级 | 条件 | 目录 |
|---|---|---|
| 1 | 设置了环境变量 `DCNEW_HOME` | 该变量指定的绝对路径 |
| 2 | 源码目录运行（项目根有 `dcnews.py`） | 项目根目录（`data/ logs/ exports/`） |
| 3 | pip 安装运行 + Windows 有 D 盘 | **`D:\dcnew`**（自动创建） |
| 4 | 兜底 | `~/dcnew` |

- `dcnew status` 会显示当前数据目录；
- 首次运行会自动把旧位置（如 site-packages 包目录内）已有的
  `news.db` 迁移到新目录，升级/卸载重装不丢数据；
- 不想用 D 盘时：`setx DCNEW_HOME "E:\my-dcnew"`（新开终端生效）。

## 项目结构

```
DongCheng-News/
├── dcnew                 # CLI 启动器（bash）
├── dcnews.py             # Python 入口
├── pyproject.toml        # pip install 支持（命令名 dcnew）
├── requirements.txt
├── dcnews/
│   ├── cli.py            # 命令体系（start/stop/status/crawl/download/latest/doctor）
│   ├── sources.py        # 57 个数据源适配器 + 注册表
│   ├── keywords.py       # 三级关键词甄别 + 单位词典 + 主题分类
│   ├── net.py            # Scrapling/requests 抓取封装（线程隔离、GBK 解码、Referer）
│   ├── enrich.py         # 文章页富化（GNE 正文/时间提取、单位与分类）
│   ├── pipeline.py       # 周期监听 / 窗口拉取 / 断点补爬
│   ├── health.py         # dcnew doctor 源健康检查（并发探测）
│   ├── daemon.py         # 后台守护进程（双 fork + PID + 日志）
│   ├── db.py             # SQLite 存储、URL/标题级去重、状态
│   ├── exporter.py       # Excel 周报（模板样式）
│   └── reporter.py       # 终端列表
├── data/                 # 运行时自动创建（news.db 等）
├── logs/                 # 运行日志（按天轮转，保留 30 天）
└── exports/              # 周报 Excel 输出目录
```
